# Stationary Refund Agent

A LangChain-based refund agent for stationary items with evaluation framework achieving 100% accuracy.

## Project Structure
`
Stationary_Refund_Agent/
+-- agent/           # Core agent logic
+-- evaluation/      # Evaluation metrics and datasets
+-- config/          # Configuration files
+-- utils/           # Utility functions
`

## Features
- Automated refund processing for stationary items
- Purchase history validation
- 30-day refund policy enforcement
- Multi-item refund support
- Comprehensive evaluation suite

## Usage
`ash
cd agent
python main.py
`

## Accuracy
Achieved 100% accuracy on all test cases.
